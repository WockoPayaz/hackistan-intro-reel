# Phase C audio audit — 15 November 2026

Before downloading, the repository was scanned for WAV, MP3, OGG, FLAC, AIFF, M4A, AAC, Opus, WebA and video containers, including hidden project files and excluding Git internals and dependency packages. No existing standalone sound assets were found. Both existing MP4s were probed and contained video only. Therefore there was no existing licensed Foley to reuse.

Freesound initially allowed individual sound-page and HQ preview access. Six CC0 recordings were acquired. Further tape, sticker, pencil and impact requests returned HTTP 403; some searches returned HTTP 429. Requests were not routed around those denials. Mixkit and Pixabay also returned HTTP 403, and no files were obtained from them.

OpenGameArt provided a permitted alternative: OwlishMedia’s CC0 recorded-household pack and AntumDeluge’s CC0 pencil pack. Only six relevant WAV members and two FLAC members were retained. All 14 source hashes are unique. Full downloads were necessary to access bundled originals, but the bundles and their hundreds of unused files are not retained in the repository.

See SFX_CATALOG.md for material-identification limitations and individual provenance. The library is real recorded audio, but some numbered stationery textures are intentional contact/adhesive substitutes, not verified literal object recordings.
